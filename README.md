# Flange Assembly Design | SolidWorks

## Project Overview
A mechanical design project focused on modeling and assembling a flange connection using SolidWorks.

The project demonstrates practical skills in 3D part modeling, mechanical assembly, and CAD design.

## Software
- SolidWorks

## Design Work
- 3D modeling of flange components.
- Bolt and nut modeling.
- Assembly of mechanical components.
- Component positioning and mates.
- 3D assembly visualization.

## Repository Structure
- `CAD/` – SolidWorks part and assembly files.
- `Drawings/` – 2D technical drawings.
- `Images/` – CAD screenshots and renders.
- `Documentation/` – Project documentation.
